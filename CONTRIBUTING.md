# Contributing

Contributions are welcome. Open an issue to discuss larger changes before starting work.

## Development setup

1. Use macOS 14 or newer and install Xcode Command Line Tools.
2. Clone the repository.
3. Build with `swift build`.
4. Run the app with `swift run Jarvis` or build an app bundle with `./packaging/build-release.sh`.

Keep changes focused, describe user-visible behavior, and include manual verification steps in pull requests. Do not commit local browser data, model weights, credentials, signing certificates, or generated app/package artifacts.
